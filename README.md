Smart Predictive Maintenance System for Conveyor Controllers

Problem Statement

A factory conveyor controller repeatedly fails, causing unexpected production downtime. This project aims to identify abnormal operating conditions early and recommend maintenance.

Objectives

- Monitor temperature, current and voltage ripple.
- Identify abnormal sensor readings.
- Display Normal, Caution and Warning status.
- Visualize readings using a dashboard.
- Recommend timely maintenance inspection.

Methodology

The system collects sensor readings or simulated inputs and compares them with predefined thresholds. If abnormal readings are detected, it displays a warning and recommends inspection.

Technologies Used

- Python
- Streamlit
- Pandas
- Data visualization

Expected Outcome

A prototype dashboard that demonstrates early fault-warning functionality and supports preventive maintenance.

Note

This initial prototype uses simulated readings. Real hardware integration and sensor calibration are future development steps.
